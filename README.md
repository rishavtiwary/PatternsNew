## ▶️ How to Run

### Prerequisites

- A C++ compiler, such as Clang or GCC.
- A terminal or command-line interface.

### Compile and run

Clone the repository:

```bash
git clone https://github.com/rishavtiwary/PatternsNew.git
cd PatternsNew
```

Compile a program:

```bash
clang++ pattern.cpp -o pattern
```

Run it on macOS or Linux:

```bash
./pattern
```

To run another program, substitute its filename. For example:

```bash
clang++ pattern2.cpp -o pattern2
./pattern2
```

Follow the input format expected by the selected program.
