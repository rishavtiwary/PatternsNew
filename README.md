# PatternsNew

A collection of C++ pattern-printing programs built while learning programming fundamentals and developing problem-solving skills.

**Language:** C++  
**Purpose:** Programming practice, logical thinking, and preparation for Data Structures and Algorithms (DSA).

PatternsNew is my personal C++ practice repository. It contains pattern-printing problems implemented using loops and nested loops.

I'm using this repository to:

- Improve logical thinking and problem-solving.
- Practise writing clean, readable code.
- Learn Git and GitHub through regular commits.
- Build a foundation for DSA and coding interviews.
